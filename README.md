# DesktopBuddy

Настольный "друг" на ESP32 с OLED-дисплеем 128x64 (SH1106). Анимированное лицо:
моргает, смотрит по сторонам, показывает эмоции. Управление тремя тач-кнопками.
Есть Wi-Fi, веб-интерфейс настройки, погода и обновление прошивки по воздуху (OTA).

Версия: v6.3

## Что умеет

- Анимированное лицо: ~60 анимаций (моргание, взгляды, эмоции, мимика)
- Три тач-кнопки для взаимодействия
- Автосон через 1 минуту простоя (любое касание будит)
- Погода с Open-Meteo, обновление раз в 15 минут
- Веб-интерфейс: город, Wi-Fi, имя/пароль точки доступа, запуск анимаций
- OTA-прошивка через веб-интерфейс (`/update`)
- Настройки хранятся в NVS (Preferences) и не сбрасываются при перезагрузке

## Железо

| Компонент | Пин ESP32 |
|-----------|-----------|
| OLED SCK  | 12 |
| OLED MOSI | 11 |
| OLED DC   | 5  |
| OLED RST  | 4  |
| OLED CS   | 6  |
| Тач TOP   | 1  |
| Тач LEFT  | 2  |
| Тач RIGHT | 3  |

OLED подключён по SPI, адрес 0x3C. Распиновка задана в `config.h`.

## Прошивка

Нужен [Arduino IDE](https://www.arduino.cc/en/software) с установленным ядром
ESP32. Через Library Manager поставьте библиотеки:

- Adafruit SH110X
- Adafruit GFX
- ArduinoJson

Затем:

1. Откройте `DesktopBuddy.ino`
2. Выберите плату ESP32
3. Нажмите "Загрузить"

## Первый запуск и настройка

Если Wi-Fi не настроен, устройство поднимает свою точку доступа:

- Имя: `DesktopBuddy`
- Пароль: `buddy1234`

Подключитесь к ней и откройте в браузере `http://192.168.4.1`.
Там можно ввести домашний Wi-Fi, город (для погоды) и часовой пояс.
После сохранения устройство перезагрузится и подключится к вашей сети.
Дальше веб-интерфейс доступен по IP устройства в локальной сети.

## Кнопки

- **Верхняя** — короткое нажатие: случайная анимация; тройное нажатие: экран
  с погодой и статусом
- **Левая / правая** — короткое нажатие: анимация; долгое (>1 с): эмоция
  "отвращение"; ещё одно короткое сразу после долгого: "злость"

## Структура

| Файл | Назначение |
|------|-----------|
| `DesktopBuddy.ino` | Основной скетч: `setup()`, `loop()`, обработка кнопок |
| `config.h`        | Пины дисплея и тач-кнопок, константы |
| `face.cpp/.h`     | Анимации лица, рендер кадра, автосон |
| `net.cpp/.h`      | Wi-Fi, точка доступа, веб-сервер, OTA |
| `settings.cpp/.h` | Чтение/запись настроек в NVS |
| `weather.cpp/.h`  | Запрос погоды с Open-Meteo |
